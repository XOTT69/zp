# Калькулятор ЗП 2/2

Статичний сайт для підрахунку зарплати за логікою таблиці **«Розрахунок ЗП 2/2 – актуально з 01.03.2026»**.

## Що вміє

- рахує норму годин по місяцях;
- додає +1 годину, якщо тести більше 80%;
- підтягує суму рейтингу по зоні 1–5;
- рахує кваліфікаційну доплату за правилами активного аркуша;
- враховує оклад, нічні години, святкові, оплату Х2, штрафи, Монобрат/таксі;
- рахує премію «Стаж» від 1 року;
- показує податок для довідки;
- дає повну деталізацію формул та попередження по нюансах.

## Формули з активного аркуша

```txt
Оплачувані години = фактичні години + 1, якщо тести > 80%
Рейтинг = lookup(зона рейтингу)
Кваліфікація:
  1-й рівень = 0
  2-й рівень = 2787, якщо зона < 4
  3-й рівень = 5574, якщо зона < 3; 2787, якщо зона = 3
Основне = (оклад + кваліфікація + рейтинг) / норма * оплачувані години
Нічні = оклад / норма * нічні години * 20%
Святкові = оклад / норма * святкові години
Х2 = (оклад + рейтинг) / норма * години Х2
Монобрат/таксі = сума / 80.5 * 100
До виплати без стажу = основне + нічні + святкові + Х2 + Монобрат/таксі - штрафи
Стаж = база стажу * (повні роки * 5%) / норма * оплачувані години
Загальна сума = до виплати без стажу + стаж
Податок = загальна сума * 23%
```

> У таблиці активного аркуша премія «Стаж» має фіксовану базу 29 991 грн. На сайті є два режими: динамічний від поточної бази або точне повторення активного аркуша.

## Запуск локально

Найпростіше запустити будь-який статичний сервер у папці проєкту:

```bash
python3 -m http.server 5173
```

Після цього відкрити:

```txt
http://localhost:5173
```
