# Калькулятор ЗП 2/2

Статичний сайт для розрахунку зарплати за логікою актуальних Google Sheets:

- `#service` - ЗП оператора сервісу 2/2
- `#supervisor` - ЗП СВ 2/2

Головна сторінка відкриває вибір потрібного розрахунку.

## Можливості

- рольовий вхід: оператор бачить тільки сервісний розрахунок, СВ бачить обидва;
- пояснення формул у блоці `Як пораховано`;
- м'які попередження для підозрілих значень;
- сценарії для порівняння різних годин, зон, стажу чи окладу;
- копіювання короткого звіту;
- кнопка `PDF`, яка відкриває друк браузера для збереження розрахунку у PDF;
- ставки та дефолтні значення винесені в `payroll-data.js`.

## Доступ

Коди ролей налаштовуються в `payroll-data.js`.

- оператор: `operator2026`
- СВ: `sv2026`

Це зручний рольовий екран для статичного сайту. Для строгого захисту даних потрібна серверна авторизація через окремий backend або auth-провайдер.

## Локальний запуск

```bash
npm run dev
```

Після запуску сайт буде доступний на `http://localhost:4174`.

## Перевірка формул

```bash
npm run verify
```

Скрипт звіряє розрахунок із прикладами з актуальних вкладок сервісу та СВ.

## Деплой на GitHub + Vercel

1. Створіть репозиторій на GitHub і запуште файли проєкту.
2. У Vercel натисніть `Add New Project`.
3. Оберіть GitHub-репозиторій.
4. Framework Preset: `Other`.
5. Build Command залиште порожнім.
6. Output Directory залиште порожнім або `.`.
7. Натисніть `Deploy`.
